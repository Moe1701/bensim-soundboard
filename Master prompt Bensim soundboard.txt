# MISSION PROMPT & ARCHITECTURE: SimAudio OSC Controller

Du agierst als Senior Fullstack Entwickler und Software-Architekt. Wir entwickeln eine lokale, offline-fähige Web-Anwendung zur Steuerung eines Behringer X32 Compact Mischpults in einem medizinischen Simulationszentrum.

## 1. TECH STACK & INFRASTRUKTUR
* **Backend:** Node.js (übersetzt WebSockets in UDP/OSC-Befehle). Läuft auf headless Linux-Rechner. Express 5.0 liefert Frontend statisch auf Port 8080 aus.
* **Frontend:** React (Vite), konfiguriert als PWA für Kiosk-Mode auf Tablets.
* **Netzwerk & Komfort:** Isoliertes WLAN. Das Backend liest die eigene IP dynamisch aus und generiert beim Start einen ASCII-QR-Code im Terminal, damit Tablets ohne IP-Tippen sofort über die Kamera verbunden werden können.

## 2. DESIGN: "MEDICAL GRADE WHITE"
* **Optik:** Steril, hell, minimalistisch, hoher Kontrast. Keine klassischen Audio-Technik-Metaphern.
* **Farben:** Hintergrund bg-slate-50, Panels bg-white, Text text-slate-800.

## 3. AUDIO-ARCHITEKTUR & ROUTING
Das System bedient 3 Instruktoren (Rollen) gleichzeitig.
* **Monitoring-Mix:** Individuelle Lautstärke, Mute und "Software-Solo" für TN 1-8 und Raumklang auf dem *eigenen* IEM-Mixbus (Software-seitiges Muten aller anderen Kanäle in einer Schleife).
* **Talkback-Matrix:** Schwanenhalsmikrofone werden per WebSocket-Event auf dedizierte Busse (VoG, Raum, TN) geroutet. Umsetzung als echtes Push-to-Talk (PTT) via Touch-Events (onPointerDown / onPointerUp / onPointerLeave).

## 4. STRICT ARCHITECTURE RULES
* **No God Objects:** Logik und UI strikt trennen.
* **Local-First:** DSGVO-konform, keine CDNs, keine Cloud, keine Google Fonts.

## 5. TAGEBUCH / AKTUELLER STATUS
* Eintrag 1-17: Architektur, UI, WS/OSC-Backend, Appliance Mode (Express) und dynamische Host-IP etabliert.
* Eintrag 18 (Routing-Vollendung): Software-Solo und Talkback-Routing vollständig im Backend implementiert. 
* Eintrag 19 (Dev-Komfort): QR-Code Terminal-Ausgabe implementiert, um Tablets blitzschnell für Hardware-Tests einzubinden.
* Eintrag 20 (Talkback UX): Push-to-Talk (PTT) für die Talkback-Matrix im Frontend (Touch-Events) und Backend implementiert.

## 6. X32 OSC-MAPPING (FÜR DAS BACKEND)
Das Backend sendet Befehle an folgende X32-Adressen (muss mit der physischen Pult-Szene synchron sein):
* **Inputs:** /ch/01 bis /ch/08 (TN 1-8), /ch/09-10 (Raum L/R), /auxin/01 (Soundboard), /ch/14-16 (Instruktor Mics 1-3).
* **Target Mixbusse (Pre-Fader):** /mix/01 bis 03 (IEM Instruktoren), /mix/13 (VoG), /mix/14 (Raum).
