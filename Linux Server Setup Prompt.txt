Bitte aktualisiere mein Projekttagebuch und den Master-Prompt für das Projekt "BenSim Soundboard". Wir haben heute einen massiven Meilenstein erreicht und den Linux-Rechner für das Rack zu einer vollautomatisierten, abgeriegelten "Appliance" (Zero-Touch) konfiguriert. 

Hier ist die Zusammenfassung dessen, was wir gebaut haben:

1. **System-Basis & Hardware-Verhalten:**
   - Node.js und PM2 sind eingerichtet, das Backend läuft als Hintergrundprozess (`bensim-osc`).
   - Der Standby-Modus beim Zuklappen des Laptops wurde deaktiviert (`HandleLidSwitch=ignore` in der `logind.conf`), damit er geschlossen im Rack weiterlaufen kann.
   - Der User `simadmin` hat eine sudo-Ausnahme für `ufw` (Firewall) erhalten, um diese passwortfrei per Skript schalten zu können.

2. **Entwickler-Workflow (Git-Sync):**
   - Wir haben den USB-Stick-Transfer beerdigt. Das Projekt wurde sauber per SSH von GitHub geklont.
   - Der Linux-Rechner wurde auf "Read-Only" gesetzt (ein `git push` wurde blockiert, um versehentliches Überschreiben zu verhindern). 
   - Code-Änderungen mache ich ab jetzt nur noch am Windows-PC und pushe sie zu GitHub.

3. **Das smarte 1-Klick-Startskript (`start-auswahl.sh`):**
   - Auf dem Desktop gibt es nun einen Start-Button, der ein grafisches Zenity-Menü öffnet.
   - **Auto-Update-Logik:** Das Skript macht bei jedem Start einen 3-sekündigen Ping zu GitHub (`git pull`). 
   - **Smart Build:** Es vergleicht die Git-Hashes. Wenn sich Dateien im Ordner `frontend/` geändert haben, führt es selbstständig `npm run build` aus. Bei Änderungen der `backend/package.json` macht es `npm install`.
   - **Lokaler Modus:** Deaktiviert die Firewall, startet PM2 und öffnet die PWA im lokalen Firefox (für Tests).
   - **Rack-Modus (Scharfschaltung):** Aktiviert die Firewall streng, setzt Ubuntu-Audio auf 100 %, startet PM2 und generiert mit `qrencode` einen QR-Code für die Tablets, der über `eog` im Vollbild angezeigt wird. Danach kann der Laptop einfach zugeklappt werden.

Was als Nächstes ansteht (Sobald das Behringer X32 geliefert wird):
- Netzwerkkabel vom Linux-PC an das X32 (oder den Rack-Switch) anschließen.
- Dem X32 im Setup-Menü die feste IP `192.168.1.100` zuweisen (wie in der `x32Client.js` hinterlegt).
- Ersten echten Hardware-Soundcheck durchführen und die OSC-Routings (Zone A, B und C) live testen.
